# VeilRaft

VeilRaft enables high-availability, real-time data processing on scalable clusters within a flexible, modular platform framework.

VeilRaft is built to be simple and practical, focusing on doing one thing well.

**Why VeilRaft?**

- processing on scalable clusters within

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/VeilRaft.git`
2. `cd VeilRaft`
3. Install in editable mode: `pip install -e .`

## Configuration

VeilRaft is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
